  Roadmap unifiée SmartLife

  Phase 1 — Tâches avancées (les 4 features forment un vrai task management pro)
  - Catégories colorées (Travail / École / Freelance / Perso / Santé)
  - Filtres + tri (date, priorité, catégorie, statut)
  - Sous-tâches / checklist dans une tâche
  - Période complète : startDate → dueDate, startTime → endTime, deadline ouverte

  Phase 2 — Alimentation Pro
  - Table user_foods dédiée (jamais toucher food_cache USDA)
  - CRUD custom : nom, macros/100g, portions personnalisées
  - Autocomplete mélange : cache global + aliments utilisateur

  Phase 3 — Sport
  - Édition complète des programmes existants
  - Auto-save + badge "Modifications enregistrées"
  - Draft persisté si on quitte sans confirmer

  Phase 4 — PWA Mobile
  - Bottom nav bar sur mobile
  - Modales plein écran mobile
  - manifest.json + service worker installable

  Phase 5 — Nouveaux modules
  - Sleep tracking (heure coucher/réveil, qualité, notes)
  - Study tracking
  - Sharing par lien
  - Social : plus tard

  Fil rouge créatif → Smart Day Score (home) : score 0-100 agrégeant tâches, calories, sport, sommeil.
