Mouvement

Le mouvement est fonctionnel: il confirme l'interaction sans ralentir l'utilisateur. Duree maximale recommandee: 300ms.

  • Apparition panneau: fadeSlideIn 0.22s ease-out pour cartes et panneaux.
  • Hover: 200ms, translateY(-2px) et ombre renforcee.
  • Glow pulse: reserve au dark mode et aux etats importants.
  • Accessibilite: desactiver translate/glow via prefers-reduced-motion.

Accessibilite

La charte impose un contraste solide et des focus states visibles sur tous les elements interactifs.

  • Contraste texte principal: viser au minimum 4.5:1. #1C1A2E sur #FFFFFF est tres confortable.
  • Accents module: les textes light sont assombris pour rester lisibles sur fonds pastel.
  • Focus: utiliser --ring-focus sur boutons, inputs, liens et menus.
  • Color scheme: declarer light/dark pour les controles natifs.

Plan De Migration CSS

Ordre conseille pour appliquer cette charte dans l'application sans casser les panneaux historiques.

Etapes

  1. Remplacer le bloc :root light de frontend/src/index.css par les nouveaux tokens.
  2. Ajouter --app-bg-gradient et l'appliquer sur body.
  3. Corriger .stat-value: retirer text-white au profit de var(--text-primary).
  4. Corriger les placeholders d'input vers --text-muted.
  5. Creer des utilitaires module-accent-* pour fonds et textes de module.
  6. Remplacer progressivement le compatibility bridge par des tokens semantiques, module par module.

Bloc CSS cible

:root {
  color-scheme: light;
