13 — Anti-patterns — ce qui est interdit
✕ Interdit dans ce thème
color: #ffffff — trop agressif sur violet
background: black / #000
rgba(0,0,0,...) pour ombres
background: #ffffff surfaces blanches
#0D1117 / #070B14 hardcodés
border-gray-* / text-gray-* non mappés
bg-white/5 inline sans token
✓ Correct
color: var(--text-primary) → #ede9ff
background: var(--surface) → #2a2550
box-shadow: var(--shadow-card)
border: 1px solid var(--border-subtle)
rgba(99,102,241,...) tintes indigo
.module-accent-{color} pour badges
var(--surface-muted) zones secondaires
